One haiku about debugging, in the 5-7-5 syllable shape. A small Node program
(`main.ts`) writes it to `/output/entry.txt` — deterministic, no network, no
input. The haiku is about a breakpoint holding the night, a cursor blinking
at three in the morning, and the turn that the fault was the author's all
along.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
